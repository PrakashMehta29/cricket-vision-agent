🚀 The Vision (Purpose & Goals)

Current cricket analytics are limited to post-match stats and basic ball-speed tracking. To solve Problem Statement 1, I built a Zero-Human-In-The-Loop Agentic Engine. This isn't just a dashboard; it’s an elite scout that thinks like a CTO. It autonomously captures telemetry that usually requires a room full of analysts.

🔥 Key Features & Capabilities

Multimodal Telemetry Extraction: Ingests raw video/image feeds using Gemini 1.5 Pro-Latest to identify shot types (e.g., Slog Sweep), delivery types (e.g., Yorker), and precise ball direction.

Predictive Strategy Matrix: Using historical player tendencies and real-time biomechanics, the agent generates a weighted probability matrix for the next delivery.

Shastri-Style AI Commentary: Converts complex JSON telemetry into a high-energy audio experience, bringing the excitement of the commentary box to the data layer.

Built in Antigravity Workspace: Fully orchestrated within the Antigravity environment, utilizing Google’s most advanced models for high-fidelity reasoning.

🛠️ Tech Stack

Core Model: Gemini 1.5 Pro (Multimodal Vision).

Environment: Antigravity IDE.

UI/UX: Streamlit (IPL Premium Dark Theme).

Audio Engine: gTTS for Real-time Commentary Synthesis.
